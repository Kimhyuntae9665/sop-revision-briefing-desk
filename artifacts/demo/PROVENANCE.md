# P13 current UI media provenance

These are actual Playwright-controlled Chrome captures of the fictional local SOP desk.
No model inference, external service, employee record, or real factory data was used for this recapture.
Script: `tests/browser_demo.py`; server: loopback 127.0.0.1:19113; desktop 1440×900; mobile 390×844.
Video was recorded by Playwright and transcoded with installed system ffmpeg, without compositing success frames.
The capture script asserted the source modal and keyboard focus return, revision/effectivity gates, read versus assessment, export, historical receipts, delayed responses, site denial and mobile width.
The screenshot files in `artifacts/demo-historical-v1` show the **previous** dark-header UI and are retained only for before/after provenance.
